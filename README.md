## 🐍 Exercícios resolvidos: Listas

| Exercício | Descrição |
|-----------|-----------|
| [`ex1.py`](lista/exercicios/ex1.py) | Lê *n* números, exibe em ordem inversa e soma os valores de posições pares e ímpares |
| [`ex2.py`](lista/exercicios/ex2.py) | Filtra as palavras maiores que um tamanho informado |
| [`ex3.py`](lista/exercicios/ex3.py) | Verifica se os elementos da lista alternam entre par e ímpar |
| [`ex4.py`](lista/exercicios/ex4.py) | Remove os elementos repetidos, mantendo a ordem original |
| [`ex5.py`](lista/exercicios/ex5.py) | Encontra o segundo maior valor da lista |
| [`ex6.py`](lista/exercicios/ex6.py) | Calcula a maior diferença entre elementos vizinhos |
| [`ex7.py`](lista/exercicios/ex7.py) | Lê notas, calcula a média e separa as notas acima e abaixo dela |
| [`ex8.py`](lista/exercicios/ex8.py) | Verifica se a lista é espelhada (palíndromo) |
| [`ex9.py`](lista/exercicios/ex9.py) | Mescla duas listas em uma nova lista ordenada |
| [`ex10.py`](lista/exercicios/ex10.py) | Lê nomes e tempos de atletas, calcula o tempo médio, lista quem ficou abaixo da média e monta o pódio |
